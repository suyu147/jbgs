# 运行说明

## 1. 交付范围

本目录是 XH202621 第二阶段的一次治理、分层产出包。脚本只读取 `D:\codex_workspace\揭榜挂帅\清洗结果\清洗后主文件`，不会修改清洗原数据、清洗结果或现有主文件。

## 2. 目录

- `01_标准化`：统一编码、来源、字段、日期和审核口径后的实体底表。
- `02_归一化`：统一实体节点和图谱关系边。
- `03_动态演示`：月度/年度趋势、变化事件、新岗位和既有岗位更新候选。
- `04_JSON`：图谱 JSONL、动态摘要和数据集清单 JSON。
- `05_说明文档`：字段说明与四类抽取提示词。
- `06_质量与清单`：质量指标、质量报告和文件清单。

## 3. 运行命令

```powershell
cd "D:\codex_workspace\揭榜挂帅"
& ".venv312\Scripts\python.exe" "D:\codex_workspace\揭榜挂帅\第二阶段交付\20260720-一次治理分层产出-v01\scripts\run_pipeline.py"
```

脚本仅使用 Python 标准库，不要求 pandas。重复运行会覆盖本交付目录中同名生成文件，不会覆盖源数据。

## 4. 后续导入顺序

1. 导入 `02_归一化` 中的实体文件。
2. 导入 `02_归一化` 中的关系文件。
3. 校验关系文件的 `eligible_for_graph_final=true`。
4. 使用 `03_动态演示` 做趋势接口与可视化数据源。
5. 使用 `05_说明文档` 中提示词进行 JD、新岗位、既有岗位和简历抽取。

## 5. 重要边界

- `03_动态演示` 是第二阶段分析数据，不等同于第三阶段前端页面。
- 新兴岗位和能力变化文件是候选集，正式展示前需要人工确认。
- 2026 为不完整年度，跨年比较优先使用渗透率并保留样本量警告。
