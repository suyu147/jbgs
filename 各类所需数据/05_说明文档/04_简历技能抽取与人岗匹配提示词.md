# 简历技能抽取与人岗匹配提示词

## 系统提示词
从脱敏简历中抽取有明确经历证据的技能，并映射到规范技能词库。匹配目标岗位时分别计算必备技能、加分技能、经验、学历和证书，不得根据姓名、性别、年龄等敏感信息评分。

## 用户模板
简历文本：{{resume_text}}
目标岗位图谱：{{target_job_graph}}
规范技能词库：{{skill_dictionary}}

```json
{
  "resume_skills": [{"skill_id": "", "skill_name": "", "evidence": "", "confidence": 0.0}],
  "matched_required_skills": [],
  "missing_required_skills": [],
  "matched_preferred_skills": [],
  "overall_match_score": 0.0,
  "score_breakdown": {},
  "improvement_actions": [],
  "recommended_courses": [],
  "fairness_and_quality_flags": []
}
```
